### Setup

```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py tailwind install
python manage.py migrate
```

### Run

##### Terminal 1

```
python manage.py tailwind start
```

##### Terminal 2

```
python manage.py runserver
```

### Requirements

- Python 3.9+
- Node.js 18+
